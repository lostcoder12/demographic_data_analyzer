# Demographic Data Analyzer

This project is part of the freeCodeCamp Data Analysis with Python certification.

## About

In this project, I used Python and Pandas to analyze demographic data from the 1994 U.S. Census database.

The program answers questions about:

- The number of people in each race
- Average age of men
- Percentage of people with a Bachelor's degree
- Percentage of people with higher education earning more than 50K
- Percentage of people without higher education earning more than 50K
- Minimum hours worked per week
- Percentage of people earning more than 50K among those working the minimum hours
- Country with the highest percentage of people earning more than 50K
- Most popular occupation in India among people earning more than 50K

## Technologies Used

- Python
- Pandas

## Dataset

The dataset is based on demographic data extracted from the 1994 Census database.
